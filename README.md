# geo — pokemon-geo-lab-api

Geografía del mundo Pokémon: regiones, towns y edificios.

**Stack:** NestJS · Drizzle · PostgreSQL — **Paradigma:** OOP + DI por decoradores, hexagonal.

```bash
npm install
npm run start:dev
```
